# Phone Online Store

The **Phone Online Store** is a simple website for browsing and managing phones.

Visitors can view available phones and search for a specific phone. The administrator can add new phones and delete existing products.

## Features

Home page

Browse phones

Search for phones

Add phones through the Admin Portal

Delete phones

## How to Run the Project

### 1. Clone the project

Open **VS Code** and open a terminal:


Run:

```bash
git clone https://github.com/evragitonga/Phone-online-store.git
```

Then enter the project folder:

```bash
cd phone-online-store
```

### 2. Install the packages

Run:

```bash
npm install
```

### 3. Start the website

Run:

```bash
npm run dev
```

Open the link provided in your browser.

### 4. Start the product database

Open a **second terminal** in VS Code and run:

```bash
npm run server
```

Keep both terminals running.

**Project:** Phone Online Store
